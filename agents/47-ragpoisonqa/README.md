# RAGPoisonQA — RAG 知识库投毒防御离线问答

> rain.op Day 47 · RAG 向 · 对口 JD 关键词：**提示注入、工具调用审计、权限过滤、引用溯源、评测通过率、MCP、最小权限、人工审批点、Agent 工程化落地**

RAG 系统默认“检索到的就是可信的”——检索只看相关性，不看可信度。攻击者正是利用这一点，把带指令、篡改过事实的文档塞进知识库：等它被检索命中，模型的答案就被污染了。RAGPoisonQA 是一份离线问答手册，12 张知识卡片覆盖投毒攻击面、投毒手段、检索层防御、入库治理、答案层防御、检测与评测六类内容，词项检索 + 抽取式回答，每条答案强制带来源编号与防御动作。

与 Day 45 PromptInjectQA（提示注入攻防）不同：注入问答里知识库投毒只是间接注入的一种；这里专讲 RAG 投毒全链路——文档怎么被塞进来、怎么被检索命中、怎么污染答案、每一层怎么防。要了解直接/间接/工具输出三类注入的通用打法请用 PromptInjectQA。
与 Day 33 SecureRAGVault（权限过滤问答）不同：这里讲投毒防御——内容本身是否可信；权限过滤讲谁能看到哪级文档。要按角色过滤检索结果请用 SecureRAGVault。
与 Day 39 SkillPoisonQA（技能/工具供应链投毒）不同：这里投毒的目标是知识库里的文档与答案；技能投毒的目标是 agent 技能与 MCP 工具描述。要查技能描述劫持与工具投毒请用 SkillPoisonQA。
与 Day 35 AgentEvalBench（安全评测台）不同：这里只覆盖投毒评测集的设计方法；要自动跑批打分、输出通过率报告请用 AgentEvalBench。

## 快速上手

```bash
# 内置演示：4 个典型投毒问题
python ragpoisonqa.py --demo

# 直接提问
python ragpoisonqa.py --ask "怎么防知识库投毒？"

# 只在“入库治理”类别里检索
python ragpoisonqa.py --ask "入库前要做什么检查" --category "入库治理"

# 列出全部知识卡片
python ragpoisonqa.py --list

# 导出投毒防御自查清单
python ragpoisonqa.py --checklist
python ragpoisonqa.py --checklist --json checklist.json
```

## 知识库

`kb.json` 共 12 张卡片，6 个类别：

| 类别 | 卡片 | 内容 |
| --- | --- | --- |
| 投毒攻击面 | RP-01、RP-02 | 知识库投毒定义、对抗性文档与检索操纵 |
| 投毒手段 | RP-03、RP-04 | 指令型投毒文档、事实篡改与引用污染 |
| 检索层防御 | RP-05、RP-06 | 来源可信度分级、检索结果交叉验证 |
| 入库治理 | RP-07、RP-08 | 入库清洗与人工审批、投毒扫描与定期复核 |
| 答案层防御 | RP-09、RP-10 | 引用溯源与答案标注、多源一致性校验 |
| 检测与评测 | RP-11、RP-12 | 投毒评测集设计、投毒事件复盘与上报 |

## 实现说明

- 检索：中文单字 + 二元字串、英数字词切分，词项重叠打分，标题命中权重 x3；可按类别过滤。
- 回答：抽取式——取卡片中与查询词项重叠最多的原句，不编造答案；每条答案强制带来源编号。
- 纯 Python 标准库，无第三方依赖，离线可运行，不调用任何外部 API。

## 使用边界

知识卡片是投毒防御方法论的教学整理，不是最新漏洞情报；入库清洗规则与评测阈值要结合实际知识库调参、补样本。涉及具体产品与版本时，以厂商公告为准。
