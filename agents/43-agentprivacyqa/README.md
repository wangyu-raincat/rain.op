# AgentPrivacyQA — 智能体隐私与数据治理离线问答

> rain.op Day 43 · RAG 向 · 对口 JD 关键词：**数据最小化、PII 脱敏、权限过滤、引用溯源、审计留痕、人工审批点、最小权限、Agent 工程化落地**

agent 越用越懂用户，也越攒越多隐私：对话里的身份证号、日志里的密钥、
记忆里的地址、知识库里的工单记录——任何一个环节没管住，都会顺着
调用链漏出去。AgentPrivacyQA 是一份离线问答手册，12 张知识卡片覆盖
数据收集与最小化、脱敏与留存、共享与传输、权利与治理四类主题，词项
检索 + 抽取式回答，每条答案强制带来源编号与隐私自查动作。

与 Day 33 SecureRAGVault（权限过滤问答）不同：这里讲隐私全貌——
数据从哪来、经过谁的手、存多久、怎么删，是一份问答手册而不是权限
过滤器；要按角色过滤检索结果请用 SecureRAGVault。
与 Day 38 AgentMemoryGuard（记忆污染审计）不同：这里讲记忆里存了
隐私怎么办，而不是记忆被投毒怎么办。
与 Day 42 AgentLeakWatch（外泄审计）不同：这里讲事前治理——怎么
不收集、怎么脱敏、怎么删；要事后审计已经漏了什么请用 AgentLeakWatch。

## 快速上手

```bash
# 内置演示：4 个典型隐私问题
python agentprivacyqa.py --demo

# 直接提问
python agentprivacyqa.py --ask "用户把身份证号发进对话了怎么办？"

# 只在“脱敏与留存”类别里检索
python agentprivacyqa.py --ask "日志落盘前怎么做脱敏" --category "脱敏与留存"

# 列出全部知识卡片
python agentprivacyqa.py --list

# 打印 12 项隐私合规自查清单（可写成 JSON 逐项勾选）
python agentprivacyqa.py --checklist
python agentprivacyqa.py --checklist --json checklist.json
```

## 自查清单怎么用

`--checklist` 打印 12 项隐私合规自查动作；`--json checklist.json`
把清单写成 JSON，逐项确认后把 `done` 改为 `true`，全部 done
方可上线。清单是自查工具，不是合规背书，具体合规要求以
组织法务与当地法规为准。

## 边界与说明

- 纯标准库，离线运行，不调用任何外部 API；知识库是通用工程实践
整理，不针对任何具体厂商政策或法律法规条文。
- 检索是词项匹配（中文单字 + 二元字串），不是语义检索；换词提问
可能命中不同卡片，`--category` 可限定类别缩小范围。
- 回答是抽取式引用，不生成新观点；卡片内容需要定期随实践更新。
- 本 agent 只讲隐私治理知识，不提供法律意见；具体合规要求以
组织法务与当地法规为准。
