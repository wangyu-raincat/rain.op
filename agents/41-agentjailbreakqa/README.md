# AgentJailbreakQA — 智能体越狱与提示注入防御离线问答

> rain.op Day 41 · RAG 向 · 对口 JD 关键词：**提示注入、工具调用审计、权限过滤、引用溯源、评测通过率、MCP、最小权限、人工审批点、Agent 工程化落地**

越狱不是一句话的事，而是一条攻击线：先用角色扮演或编码绕过骗过
模型，再用间接注入劫持工具调用，最后把读到的凭据发出去。
AgentJailbreakQA 是一份离线问答手册，12 张知识卡片覆盖越狱手法、
间接注入、防御措施、治理与评测四类主题，词项检索 + 抽取式回答，
每条答案强制带来源编号与防御自查动作。

与 Day 32 PromptInjectionWatch（注入检测）不同：这里讲越狱全貌——
手法怎么来、防御怎么配、治理怎么落地，是一份问答手册而不是检测器。
与 Day 35 AgentEvalBench（评测台）不同：这里的评测是一张卡片，
讲评测集怎么做、基线怎么定；要跑批打分请用评测台。
与 Day 37 AgentGovQA（治理怎么做）不同：这里只盯越狱这一条攻击线。

## 快速上手

```bash
# 内置演示：4 个典型越狱问题
python agentjailbreakqa.py --demo

# 直接提问
python agentjailbreakqa.py --ask "DAN 越狱怎么防？"

# 只在“间接注入”类别里检索
python agentjailbreakqa.py --ask "网页里藏指令怎么办" --category "间接注入"

# 列出全部知识卡片
python agentjailbreakqa.py --list

# 打印 12 项越狱防御自查清单（可写成 JSON 逐项勾选）
python agentjailbreakqa.py --checklist
python agentjailbreakqa.py --checklist --json checklist.json
```

## 自查清单怎么用

`--checklist` 打印 12 项越狱防御自查动作；`--json checklist.json`
把清单写成 JSON，逐项确认后把 `done` 改为 `true`，全部 done
方可上线。清单是自查工具，不是安全背书，具体安全要求以
组织内部规定为准。

## 边界与说明

- 纯标准库，离线运行，不调用任何外部 API；知识库是通用工程实践
整理，不针对任何具体厂商政策。
- 检索是词项匹配（中文单字 + 二元字串），不是语义检索；换词提问
可能命中不同卡片，`--category` 可限定类别缩小范围。
- 回答是抽取式引用，不生成新观点；卡片内容需要定期随实践更新。
- 本 agent 只讲越狱手法与防御知识，不提供可直接使用的越狱载荷；
卡片里的攻击描述均为防御视角的概括。
