# PHPatchWatch 🛡️

针对 **CVE-2026-109618 / CVE-2026-109619**（PHP 核心 RCE，代号 PHP2Shell，CVSS 9.2）
的暴露面盘点与补丁就绪度评估 agent。给你一组主机的 PHP 版本标识
（`X-Powered-By` / `Server` 头 / `phpinfo` 版本串），逐台判定是否在受影响分支、
是否已打上官方紧急补丁，按 0–100 打风险分并给出升级处置建议。

## 漏洞背景

- CVE-2026-109618 / CVE-2026-109619：PHP 核心双 RCE，embargo 2026-10-20 被匿名帖提前破裂，官方紧急补丁 **2026-10-21 22:00（北京时间）** 发布。
- 修复版本：**8.5.12 / 8.4.27 / 8.3.36 / 8.2.35**；**8.1 及更早分支 EOL，无补丁**（永不会有 PHP2Shell 修复）。
- 截至编写时：无确认的野外利用，未进入 CISA KEV。Sansec「补丁后 15 分钟大规模利用」为预测非事实。

## 评估逻辑

| 状态 | 判定 | 基础分 |
|---|---|---|
| 已修复 | 分支在修复列表内且版本 ≥ 修复版本 | 5 |
| 受影响·有补丁 | 8.2–8.5 分支，版本 < 修复版本 | 95 |
| 受影响·EOL 无补丁 | 8.1 及更早 / 7.x / 5.x | 100 |
| 未知 | 版本标识缺失或无法解析 | 30 |

`X-Powered-By` / `Server` 头明文暴露版本号 → +5 分（便于攻击者定向）。
每台输出判定证据链（解析出的版本、补丁目标）与一条可执行的处置建议。

## 怎么跑

纯标准库，无需安装：

```bash
python phpwatch.py --demo                      # 内置演示：6 台样本主机
python phpwatch.py --csv hosts.csv              # CSV 列：name,banner
python phpwatch.py --demo --json                # JSON 输出，接 SIEM/资产系统
```

`hosts.csv` 示例：

```csv
name,banner
web-01,X-Powered-By: PHP/8.4.27
web-02,X-Powered-By: PHP/8.3.20
web-03,Server: Apache/2.4.57 (Unix) PHP/7.4.33
```

## 局限

- 只做「版本 vs 补丁」判定，不做漏洞利用检测；补丁是否真正生效以官方公告为准。
- 修复版本表基于 2026-10-21 紧急补丁，后续分支更新需手工同步 `FIXED` 表。
- 隐藏版本头的资产（`Server: nginx` 形态）只能标为「未知」，需要人工确认。
