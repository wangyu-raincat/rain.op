# MITRE-QA 🎯 MITRE ATT&CK 战术技战术离线问答

离线运行的 ATT&CK 问答 agent：用 **BM25 检索**内置的 18 条真实 MITRE ATT&CK
技术知识库，回答"这是什么攻击手法、属于哪个战术、怎么检测/缓解"，输出
结构化**战术卡片**。纯 Python 标准库，clone 下来就能跑，不依赖任何外部 API。

方向：**RAG**（检索增强问答）

## 能做什么

- 🆔 **按编号精确查询**：`T1059` / `T1486` 直接命中知识库条目
- 🔍 **自然语言提问**：中文问句经分词（英文单词 + 中文字符二元组）后做 BM25 检索，
  编号/名称/关键词字段加权，返回最相关的 3 张战术卡片
- 🃏 **战术卡片**：技术编号、名称、所属战术、适用平台、简介、检测思路、缓解措施一目了然
- 📚 **知识库**：18 条真实 ATT&CK 技术，覆盖初始访问 → 执行 → 持久化 → 防御规避 →
  凭证访问 → 发现 → 横向移动 → 命令与控制 → 渗出 → 影响全杀伤链
  （钓鱼 T1566、PowerShell 滥用 T1059、Mimikatz 转储 T1003、勒索加密 T1486…）

## 怎么跑

```bash
cd agents/08-mitre

# 演示模式：自动回答 4 个示例问题
python mitre.py --demo

# 直接提问
python mitre.py "勒索软件常用哪些攻击手法？"
python mitre.py "内网横向移动一般用什么技术"
python mitre.py "mimikatz 是什么技术"

# 按 ATT&CK 编号精确查询（大小写不敏感）
python mitre.py --id T1059

# 列出知识库全部 18 条技术
python mitre.py --list
```

需要 Python 3.8+，无第三方依赖（无 `requirements.txt`）。
