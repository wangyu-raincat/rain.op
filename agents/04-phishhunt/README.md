# PhishHunt · 钓鱼邮件智能分析

`rain.op` 每日安全小 Agent 系列的第 4 个：**RAG** 方向。

粘贴一封可疑邮件，PhishHunt 会自动做四件事：

1. **解析邮件**：提取 From / Reply-To / Subject / 正文 / 链接
2. **特征提取**：13 类钓鱼特征检测（回复地址不一致、发件人冒充、IP 直连链接、
   短链、仿冒域名、紧迫性话术、索取密码验证码、危险附件、HTML 附件、
   泛化问候语、中奖诱饵、财务社工、二维码）
3. **RAG 检索**：每条命中特征用 BM25 在内置钓鱼知识库（16 条）中检索解释，生成带引用的证据链
4. **风险评分**：0–100 分三档判定（安全 / 可疑 / 高危），高危邮件附处置建议

纯 Python 标准库，**离线可运行**，无需 API Key。

## 目录结构

```
agents/04-phishhunt/
├── phishhunt.py       # 主程序：解析 → 特征提取 → BM25 检索 → 评分
├── kb.json            # 钓鱼特征知识库：16 条（冒充/链接/附件/话术/处置）
├── requirements.txt   # 纯标准库，无第三方依赖
└── README.md          # 本文件
```

## 怎么跑

```bash
# 演示模式：内置 1 封钓鱼邮件 + 1 封正常邮件
python phishhunt.py --demo

# 分析本地邮件文本文件
python phishhunt.py --file mail.txt

# 直接分析一小段文本
python phishhunt.py --text "尊敬的用户，请点击 http://bit.ly/xxx 立即验证您的账户"

# 管道输入
cat mail.txt | python phishhunt.py
```

## 原理

1. **特征提取（规则层）**：正则 + 域名分析。仿冒域名检测用归一化
   （`0→o`、`1→l` 去连字符）后匹配品牌词表，并维护一份官方域名白名单；
   品牌词出现在子域名位置（如 `paypal.xxx.cn`）同样会被标记。
2. **RAG（检索层）**：每条命中特征的中文描述作为查询，用 BM25
   （中英混合分词：英文按词、中文按字二元）在 `kb.json` 中检索 top-2，
   作为"为什么这是钓鱼特征"的解释引用。
3. **评分层**：各特征有权重（5–25），命中 ≥3 项再 +10，上限 100；
   ≥70 高危，≥35 可疑，其余安全。

## 局限

- 规则 + 关键词驱动，对精心伪装的鱼叉式钓鱼（Spear Phishing）覆盖有限；
- 不解析真实邮件 MIME 结构，只按文本头简单解析；
- 品牌词表/官方域名表是内置小表，可自行扩展。
