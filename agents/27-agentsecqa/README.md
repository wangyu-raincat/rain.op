# AgentSecQA

AI 智能体安全离线问答：针对智能体（Agent）特有的安全风险做知识检索与抽取式回答，纯标准库，离线可运行，不联网、不调用外部 API。

## 它是做什么的

大模型智能体比传统应用多了一层风险：它会读外部内容、调工具、写记忆、跑代码——每一步都可能被注入或误用。AgentSecQA 内置 12 张知识卡片，覆盖：

- 间接 / 直接提示注入
- 工具最小权限与写操作审批
- MCP 工具投毒、插件与技能投毒
- 数据外泄、记忆污染、多智能体级联风险
- 代码执行沙箱、身份混淆、输出校验
- 上线前八项自查清单

## 怎么跑

```bash
python agents/27-agentsecqa/agentsecqa.py --demo
python agents/27-agentsecqa/agentsecqa.py --ask "什么是间接提示注入？怎么防？"
python agents/27-agentsecqa/agentsecqa.py --list
```

`--ask` 会按词项重叠打分（标题命中权重最高），输出最相关的卡片原文并标注卡片编号与匹配分，便于核对来源。

## 示例输出

```text
问题：什么是间接提示注入？怎么防？

[1] 间接提示注入：外部内容里的隐藏指令（匹配分 18）
间接提示注入：攻击者把指令藏进智能体读取的外部内容（网页、邮件、文档、工具返回结果）里……
标签：提示注入、间接注入、外部内容
```

## 边界说明

- 知识卡片讲的是通用防御思路，不是针对某个具体产品或版本的审计结论。
- 检索是词项匹配，不是语义理解；换个关键词往往能命中更相关的卡片。
- 落地到自家智能体时，请结合实际的工具清单、权限配置与调用日志复核。
