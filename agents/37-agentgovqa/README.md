# AgentGovQA — 智能体治理与合规离线问答

> rain.op Day 37 · RAG 向 · 对口 JD 关键词：**最小权限、人工审批点、MCP、工具调用审计、引用溯源、Agent 工程化落地**

agent 能跑起来只是第一步，能不能放心上线才是工程化的分水岭。AgentGovQA
回答「agent 落地时治理怎么做」的问题：权限怎么给、审批设在哪、
MCP 第三方工具怎么准入、审计记什么、敏感数据怎么管、记忆谁说了算、
上线前要过哪些关。12 张知识卡片全部离线，词项检索 + 抽取式回答，
**每句答案强制带来源编号与治理域**，并附一条可执行的落地动作。

与 Day 27 AgentSecQA（攻击手法问答）不同：这里不讲攻击怎么打，
讲治理怎么做 —— 是「防住之后怎么管住」的配套工具。

## 快速上手

```bash
# 内置演示：4 个典型的 agent 治理问题
python agentgovqa.py --demo

# 提问
python agentgovqa.py --ask "工具权限怎么给？"
python agentgovqa.py --ask "MCP 怎么管" --category "MCP 治理"

# 列出全部 12 张知识卡片
python agentgovqa.py --list

# 上线前治理检查清单（12 项，逐项确认）
python agentgovqa.py --checklist
python agentgovqa.py --checklist --json checklist.json
```

## 知识库覆盖的 12 个治理域

| 治理域 | 卡片 | 核心问题 |

| 权限治理 | GOV-01 | 工具权限按任务按需授予，参数级限制 |
| 审批流程 | GOV-02 | 删改/写库/外发/动生产四类调用必须人工审批 |
| MCP 治理 | GOV-03 | 第三方 MCP server 准入评审、版本固定、描述清洗 |

| 数据合规 | GOV-05 | PII 不进提示词与日志、数据驻留、检索前分级过滤 |
| 提示注入治理 | GOV-06 | 指令与数据分离、网关清洗、注入回归 |
| 记忆治理 | GOV-07 | 记忆写入审批、租户隔离、定期清理 |
| 配额成本 | GOV-08 | token/调用/费用三级配额、异常消费告警 |
| 供应链治理 | GOV-09 | 依赖评审、SBOM 思路、密钥轮换 |
| 上线发布 | GOV-10 | 五关检查、灰度、回滚 |
| 事故复盘 | GOV-11 | 止血/复盘/改进闭环 |
| 评测基线 | GOV-12 | 五类场景评测集、回归基线留档 |

## 检查清单怎么用

`--checklist` 打印 12 项上线前自查动作；`--json checklist.json`
把清单写成 JSON，逐项确认后把 `done` 改为 `true`，全部 done
方可上线。清单是自查工具，不是合规背书，具体行业监管要求以
主管单位规定为准。

## 边界与说明

- 纯标准库，离线运行，不调用任何外部 API；知识库是通用工程实践
整理，不针对任何具体厂商政策。
- 检索是词项匹配（中文单字 + 二元字串），不是语义检索；换词提问
可能命中不同卡片，`--category` 可限定治理域缩小范围。
- 回答是抽取式引用，不生成新观点；卡片内容需要定期随实践更新。
