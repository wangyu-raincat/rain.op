# FlowScan · 轻量流量异常检测

`rain.op` 每日安全小 Agent 系列的第 1 个：**流量监测**方向。

一句话：用纯启发式规则（无机器学习、无外部依赖）分析 NetFlow 风格的流量日志，检测端口扫描、SYN Flood、内网 Beacon 三种常见网络异常。纯 Python 标准库，离线可运行。

## 核心功能

- **端口扫描检测**：同一 (源, 目标) 在滑动窗口内触及的去重端口数超过阈值即告警。
- **SYN Flood 检测**：统计窗口内纯 SYN（半开）连接数，识别洪泛式半开连接堆积。
- **内网 Beacon 检测**：内网主机以高度规律的固定间隔外联（间隔变异系数 CV < 0.2），疑似 C2 心跳。
- **双通道输出**：控制台可读报告 + JSON 结构化告警文件，便于下游 SIEM 接入。
- **自带样本生成器**：`gen_sample.py` 一键生成含 3 种植入攻击的合成流量，开箱即可验证检测效果。

| 检测项 | 规则 | 严重度 |
|---|---|---|
| 端口扫描 `port_scan` | 单源在 60s 窗口内探测同一目标 ≥15 个端口 | 高危 |
| SYN Flood `syn_flood` | 单源在 60s 窗口内发起 ≥100 个半开 SYN 连接 | 高危 |
| 内网 Beacon `beaconing` | 内网主机以固定间隔（变异系数 <0.2）规律外联 ≥6 次 | 中危 |

## 快速开始

环境：Python 3.8+，无第三方依赖（`requirements.txt` 为空依赖说明）。

```bash
cd agents/01-flowscan

# 一键演示：生成合成流量（含 3 种植入攻击）并检测
python flowscan.py --demo

# 检测自己的流量文件
python flowscan.py -i flows.csv -o alerts.json

# 自定义滑动窗口（秒）
python flowscan.py -i flows.csv --window 120

# 单独生成样本数据
python gen_sample.py -o sample.csv --flows 2000 --seed 42
```

退出码：检出高危告警时返回 1（演示模式下属预期行为），便于接入 cron / 流水线做成败判断；无高危返回 0。

## 输入格式

CSV，表头：`ts,src_ip,dst_ip,src_port,dst_port,proto,packets,bytes,tcp_flags`

- `ts`：Unix 时间戳（秒）
- `tcp_flags`：`S` / `SA` / `A` / `F` / `R` 等组合；UDP 留空

```csv
ts,src_ip,dst_ip,src_port,dst_port,proto,packets,bytes,tcp_flags
1727962800,192.168.1.50,10.0.0.5,40001,22,TCP,1,60,S
1727962801,192.168.1.50,10.0.0.5,40002,80,TCP,1,60,S
```

坏行（时间戳非法、字段缺失）在载入时自动跳过，不中断整批分析。

## 参数

- `--window N`：滑动窗口秒数（默认 60），端口扫描 / SYN Flood 共用
- `-o FILE`：JSON 告警输出路径（默认 `alerts.json`）

## 设计要点

- **滑动窗口 + 计数维护**：端口扫描与 SYN Flood 都按 (源, 目标) 分组后用双端队列做滑动窗口，端口计数随窗口进出增减，全程 O(n) 一遍扫完，不做全量排序比对。
- **Beacon 用变异系数而非方差**：间隔的规律性用 CV = 标准差 / 均值衡量，与心跳周期长短无关——120 秒和 1800 秒的心跳只要足够规律都能命中，同时均值落在 [20s, 7200s] 才判定，排除掉过密/过稀的正常轮询。
- **检测与报告解耦**：三个检测器各自返回统一结构的告警 dict，`analyze()` 只负责汇总与按严重度排序，新增检测规则只需再写一个返回同结构列表的函数。
