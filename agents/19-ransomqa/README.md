# RansomQA 🛡️ 勒索软件应急响应离线问答

第 19 个每日安全小 agent，方向：**RAG**。

知识库围绕 **2026-10-20 刚发布的联合通告 AA26-293A**
（`#StopRansomware: SafePay Ransomware`，FBI / CISA / 美国特勤局 /
德国莱法州刑警 / 英国 NCA 联合发布）构建：SafePay 自 2024-08 活跃至今，
已波及约 600 家组织，典型手法是**双重勒索**（先窃数据再加密，拒付就公开），
主入口是 VPN/边界设备漏洞、被盗凭证和钓鱼。

18 张知识卡片分两类：
- **威胁情报卡**（5 张）：SafePay 组织画像、初始入侵方式、攻击链/TTP、
IOC（含脱敏 IP 与 STIX 情报说明）、官方缓解措施
- **应急响应 Playbook 卡**（13 张）：第一小时隔离保全、遏制、根除、恢复、
3-2-1 备份防护、付不付赎金决策、谈判要点、合规报告、威胁狩猎、
VPN 加固、钓鱼自查、应对电话施压、事后复盘

## 怎么跑

纯标准库，无需安装，无需 API Key，离线可运行：

```bash
cd agents/19-ransomqa

# 演示模式：自动跑 7 个示例问题
python ransomqa.py --demo

# 单次提问
python ransomqa.py --query "SafePay 是怎么进来的"

# 交互模式
python ransomqa.py

# 列出全部知识卡片
python ransomqa.py --list
```

需要 Python 3.8+。

## 实现原理

- **检索**：BM25（k1=1.5, b=0.75），中文按单字 + 英文按词混合分词，
卡片标题/关键词/正文联合建索引
- **回答**：抽取式——对命中卡片按句子打分（与问题的 token 重叠度 +
关键词命中加权），取 top 句子拼成回答，并给出引用卡片
- 检索无命中时如实告知，不编造答案

## 示例输出

```
$ python ransomqa.py --query "发现被勒索加密，第一个小时该做什么"
(BM25=8.214)
发现勒索加密迹象后的第一个小时只做四件事：（1）隔离受影响主机——拔网线/
禁用网卡/挂起虚拟机，优先断网不断电，避免内存证据丢失；（2）保全证据——
内存镜像、系统与安全日志、勒索信原样保留，不要急着重装；（3）判定范围——
哪些网段、哪些备份受影响，VPN 会话是否异常；（4）拉起应急小组并冻结变更。
禁忌：不要先谈赎金、不要全网关机、不要在查清入口前恢复业务。
引用：ir-first-hour 应急第一小时：隔离与保全证据；safepay-ttps SafePay 攻击链与破坏手法
```
