# PromptInjectQA — 提示注入攻防离线问答

> rain.op Day 45 · RAG 向 · 对口 JD 关键词：**提示注入、工具调用审计、权限过滤、引用溯源、评测通过率、MCP、最小权限、人工审批点、Agent 工程化落地**

agent 越来越能干，也越来越容易被“骗”：用户输入里的一句“忽略之前所有指令”、网页里藏的一行恶意指示、工具返回结果里的一条假命令，都可能让模型把攻击者的指令当成自己的任务执行。PromptInjectQA 是一份离线问答手册，12 张知识卡片覆盖直接注入、间接注入、工具输出注入三类攻击面，以及输入净化、注入检测、最小权限、沙箱隔离、评测集与事件复盘六类防御，词项检索 + 抽取式回答，每条答案强制带来源编号与防御动作。

与 Day 41 AgentJailbreakQA（越狱问答）不同：这里讲控制权争夺——攻击者怎么夺走 agent 的指令权、怎么沿调用链放大；越狱只讲模型安全边界怎么被绕过。要了解越狱话术与对齐绕过请用 JailbreakQA。
与 Day 33 SecureRAGVault（权限过滤问答）不同：这里讲注入攻防——知识库投毒只是间接注入的一种；要按角色过滤检索结果请用 SecureRAGVault。
与 Day 34 MCPGuard（调用时拦截）不同：这里是问答手册——讲注入从哪来、怎么防、怎么评测；要实时拦截危险工具调用请用 MCPGuard。
与 Day 35 AgentEvalBench（安全评测台）不同：这里只覆盖注入评测集的设计方法；要自动跑批打分、输出通过率报告请用 AgentEvalBench。

## 快速上手

```bash
# 内置演示：4 个典型注入问题
python promptinjectqa.py --demo

# 直接提问
python promptinjectqa.py --ask "怎么防间接注入？"

# 只在“工具输出注入”类别里检索
python promptinjectqa.py --ask "工具返回里有注入怎么办" --category "工具输出注入"

# 列出全部知识卡片
python promptinjectqa.py --list

# 导出注入防御自查清单
python promptinjectqa.py --checklist
python promptinjectqa.py --checklist --json checklist.json
```

## 知识库

`kb.json` 共 12 张卡片，6 个类别：

| 类别 | 卡片 | 内容 |
| --- | --- | --- |
| 直接注入 | PI-01、PI-02 | 直接注入定义、越狱与注入的区别 |
| 间接注入 | PI-03、PI-04 | 间接注入、RAG 知识库投毒与引用溯源 |
| 工具输出注入 | PI-05、PI-06 | 工具返回里的注入、多步调用链放大 |
| 防御-输入层 | PI-07、PI-08 | 输入净化与指令分隔、注入检测器 |
| 防御-架构层 | PI-09、PI-10 | 最小权限与工具调用审计、沙箱与数据隔离 |
| 检测与评测 | PI-11、PI-12 | 注入评测集设计、注入事件复盘与上报 |

## 实现说明

- 检索：中文单字 + 二元字串、英数字词切分，词项重叠打分，标题命中权重 x3；可按类别过滤。
- 回答：抽取式——取卡片中与查询词项重叠最多的原句，不编造答案；每条答案强制带来源编号。
- 纯 Python 标准库，无第三方依赖，离线可运行，不调用任何外部 API。

## 使用边界

知识卡片是攻防方法论的教学整理，不是最新漏洞情报；注入检测规则与评测用例要结合实际系统调阈值、补样本。涉及具体产品与版本时，以厂商公告为准。
