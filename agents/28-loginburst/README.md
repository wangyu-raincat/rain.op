# LoginBurst 登录爆破 / 撞库检测

分析 Web 访问日志中的登录请求，按源 IP 聚合，用五组启发式规则打 0–100 风险分，
识别暴力破解、撞库和密码喷洒。纯 Python 标准库，离线可运行，不发起任何网络请求。

## 它是做什么的

很多登录攻击在单条日志里看不出异常，聚合成“同一 IP 的行为”才现形。LoginBurst
检查五组信号：

| # | 规则 | 说明 |
| --- | --- | --- |
| 1 | 登录失败爆发 | 5 分钟内登录失败 ≥ 20 次即满分（30 分） |
| 2 | 撞库特征 | 同一 IP 尝试不同用户名 ≥ 10 个即满分（25 分） |
| 3 | 爆破后成功 | 多次失败后出现登录成功，疑似账号已被攻破（25 分） |
| 4 | 密码喷洒 | 很多账号、每账号只失败 1~2 次，绕过单账号锁定（10 分） |
| 5 | 自动化特征 | 脚本类 User-Agent、缺失 UA、极高请求速率（10 分） |

风险分 ≥ 70 为高危，40~69 为中危。出现高危告警时程序按设计返回退出码 1，
便于接入定时任务或告警脚本。

## 怎么跑

```bash
# 内置演示：1 个正常用户、1 个撞库后成功、1 个密码喷洒
python loginburst.py --demo

# 分析自己的日志（Apache combined log 格式，登录路径需含 login/signin/auth）
python loginburst.py -i access.log -o alerts.json

# 附带的演示日志文件
python loginburst.py -i sample.log
```

## 输入格式

每行一条 Apache combined log，登录请求需满足：

- 请求路径含 `login`、`signin`、`auth`、`oauth` 或 `session`（不区分大小写）；
- 用户名从查询参数 `user`、`username`、`login`、`account` 中提取（可选，没有也能跑，
  只是规则 2、4 无法触发）；
- 状态码：401/403 计为失败，200/302 计为成功。

示例：

```
203.0.113.7 - - [02/Nov/2026:08:20:00 +0800] "POST /login?user=user00 HTTP/1.1" 401 512 "python-requests/2.31"
```

## 限制与注意事项

- 只看访问日志：POST body 里的用户名、验证码失败、账号锁定事件都不在日志里，
  因此只能做“嫌疑”判定，不能定罪；高危 IP 建议结合 WAF/风控日志复核后再封禁。
- 分布式慢速爆破（多 IP、低频、长周期）会低于阈值，需要更长窗口或跨 IP 聚合。
- 阈值写在 `loginburst.py` 顶部常量区，可按自己站点的正常登录量调整；
  登录量大的站点建议先调高失败爆发阈值，避免正常用户被误报。
- 演示中的 IP 均为文档保留地址（203.0.113.0/24、192.0.2.0/24、198.51.100.0/24），
  不指向真实主机；本工具只分析日志，不会向示例 IP 发起任何探测。
